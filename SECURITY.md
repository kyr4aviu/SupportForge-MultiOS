# Security Policy

## Supported version

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| 0.x | No |

## Reporting a vulnerability

Do not publish exploit details or sensitive system data in a public issue.

Provide:

- affected version;
- operating system;
- command used;
- minimal reproduction;
- expected and actual behavior;
- impact assessment;
- sanitized logs.

## Security boundaries

SupportForge is designed for local read-only diagnostics. It does not claim compliance
certification. Deployment approval depends on the complete accredited environment,
configuration baseline, operating procedures, and supply-chain controls.
