# Roadmap

## Current: 1.0.x

- macOS Intel host validation
- Linux GUI smoke testing in Alpine
- Cross-platform system, network, storage, service, and log collectors
- Docker and PostgreSQL diagnostics
- Redacted HTML/JSON incident bundles and snapshot comparison

## Next

- Native Linux VM validation and launcher
- Native Windows validation and launcher
- Platform-specific packaging and signing instructions
- Additional tests for restricted-permission and unavailable-service states

Roadmap items are not release commitments. Platform-specific artifacts are only
described as validated after testing on their target operating system.
